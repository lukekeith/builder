# The test plan — implementation plan

**Spec:** `docs/specs/2026-10-23-test-plan-design.md` — read it first; this plan does not restate
its why. **Branch:** `feat/test-plan`. **Release:** 4.12.0 (minor).

## The contract (every task codes against this — do not rename)

**The manifest line** (written at the go-ahead, or ahead by `/builder:agent` / `/builder:fleet`):

```
tests: slice=own end=touched review=end
```

Optional extra pairs, only when not the default: `models=economy|strong`, `persist=low`,
`unruled=park`, `walk=you` (agent builds: the human walks after the agent).

**The levers** (`scripts/profile.mjs`):

| Lever | Values (recommended first) | Meaning |
|---|---|---|
| `slice` | `own` · `own+app` · `full` · `none` | after each task: its own tests + type-check · plus the app's fast set at the phase close (today) · the app's fast set after every task · type-check only |
| `end` | `touched` · `risk` · `everything` · `none` | verify `floors` (today's) · + `[risk]` agent walk, verify `full` · full walk, verify `everything` · type-check only |
| `review` | `end` · `app` · `slice` | final whole-branch review only · one review per phase close · a task review after every task (today) |
| `models` | `default` · `economy` · `strong` | unchanged |
| `persist` | `default` · `low` | unchanged |
| `unruled` | `recommend` · `park` | unchanged |
| `walk` | (absent) · `you` | today's `thorough-you` |

**Floors** (hold under every plan): the type-check of every touched app before the work lands, and
the final whole-branch review. The type-check is the config's fast-set lines marked `@typecheck`
(a new, optional gate-line marker); an app with none marked relies on the implementer's per-task
type-check, and verify says so in one line.

**Old manifests** — `profile:` and no `tests:` — map (spec §6):
`rush` → `slice=own+app end=touched review=end models=economy persist=low` ·
`standard` → `slice=own+app end=risk review=slice` ·
`thorough` → `slice=own+app end=everything review=slice` ·
`thorough-you` → thorough + `walk=you` · `custom k=v` → old keys translated
(`testing none|risky|full|full+human` → `end` touched|risk|everything|everything+walk=you;
`review final|per-task|per-task+second` → `end`|`slice`|`slice` (+second kept as `review=slice+second`);
`verify floors|full|everything` → raises `end` to at least touched|risk|everything) ·
neither line on a go-ahead'd feature → the thorough mapping (the pipeline it was approved under).
`build_profile_default:` in the config is still read: its preset's mapping is the recommendation
when no signal applies.

**The label** (status, fleet tables): `own · touched · end` (the three values, `·`-joined), with
` · you` when `walk=you`, and `here` for `build: here`.

## Tasks

Tasks 1–4 are scripts (TDD, `node --test scripts/test/`); 5–8 are skill prose and can run beside
them because they code against the contract above. Nobody commits inside a task — the controller
commits each batch.

### Task 1 — `scripts/profile.mjs`: the test-plan model
- `TEST_LEVERS`, `RECOMMENDED`, `FLOORS = { typecheck: true, finalReview: true }`.
- `parseTestPlan(manifest)` → `{ levers, label, source: 'tests'|'profile'|'default', warning }`;
  takes the parsed manifest object (`tests`, `profile`, `go-ahead`, `build`). Unknown pair → ignored
  with a warning, like `parseProfile` today. Keep `parseProfile` exported as a thin wrapper returning
  `{ preset, levers, … }` only if a consumer still needs it after Task 4 — otherwise remove it.
- `formatTests(levers)` → the manifest value; `planLabel(levers)` → the label.
- `recommend({ specText, planText, cfg })` → `{ tests: { slice, end, review }, signals, reason }`.
  Base = recommended. Signals (the same five as today) raise **only** `end` to `risk`, `reason`
  naming them. `cfg.buildProfileDefault` set → its mapping when there is no signal. Never `slice=full`.
- `cost({ planText, levers, durations })` → `{ slices, apps, phases, ownRuns, suiteRuns, reviews,
  walk: 'none'|'risk'|'full', minutes: number|null }`. ownRuns = tasks unless `slice=none`;
  suiteRuns = (own+app → phases · full → tasks · else 0) + (end≠none → apps); reviews =
  (slice → tasks · app → phases · end → 0) + 1, the final whole-branch review.
  minutes = Σ suite runs × that app's recorded fast-set duration (Task 3's `durations`) when every
  needed app has one; else null.
- `estimate(rows, label, tasks)` keyed by `r.tests` (a manifest value → its label) or, for old
  rows, `r.profile` mapped → label.
- CLI: `--levers <folder>`, `--recommend <folder>`, `--estimate <folder> --tests "<value>"`,
  `--cost <folder> --tests "<value>"` (reads durations via Task 3's export).
- Rewrite `scripts/test/profile.test.mjs` for all of it, including every mapping row.

### Task 2 — `scripts/plan-slices.mjs` (new): the slice table
- `slices(planText)` → `[{ n, app, phase, name, tests }]` from `### Task N: <name>` blocks with
  their `App:` / `Phase:` lines; `tests` = count of test cases in the block's code fences
  (`it(`, `test(`, `def test_`, `func Test`, `#[test]`), 0 → shown `—`.
- `render({ feature, target, slices, cost, levers, recommended })` → the text block of spec §1 (app
  name once per group, right-aligned `+N tests`, the two test-plan lines, minutes only when known).
- CLI: `node scripts/plan-slices.mjs <folder> [--tests "<value>"] [--json]` — default levers =
  `profile.mjs` recommend for that folder.
- `scripts/test/plan-slices.test.mjs` with a fixture plan.

### Task 3 — gate durations and `@typecheck`
- `gates-core.mjs`: after a green run of a whole (unscoped) set, record each command's `ms` in
  `.builder/gates/durations.json` `{ <app>: { total, commands: { <cmd>: ms } , at } }`; export
  `readDurations(root)`.
- The `@typecheck` marker: parsed like `@known-red`/`@delta`; `gate.mjs <app> --typecheck` runs
  only the marked lines (none marked → prints `no @typecheck line for <app>` and exits 0).
- `PROJECT.template.md` §Quality gates: one bullet for `@typecheck`.
- Tests in `scripts/test/gates-core.test.mjs`.

### Task 4 — the scripts that read the plan
- `list-features.mjs`, `fleet.mjs`, `fleet-core.mjs`: `parseProfile(...).preset` → `parseTestPlan`
  label/levers; `persist` from levers; fleet archive rows record `tests: <formatTests>` beside the
  old `profile` key.
- `scripts/bench.mjs` + `bench/` configs: builder configs become `builder` (no `tests:` pre-set —
  the recommendation) and `builder-everything` (`slice=own+app end=everything review=slice`).
- Update every test these touch (`fleet*.test.mjs`, `list-features*.test.mjs`, `bench*.test.mjs`).

### Task 5 — `skills/plan`: the go-ahead
- §The go-ahead: present `node <builder>/scripts/plan-slices.mjs <folder>` verbatim, then the
  lettered A/B/C (CONVERSATION §Ways on style: *Build it with this plan* · *Change the test plan* ·
  *Keep planning*, "go" is A). Applies in chat and with an `agent_walk:` block alike.
- B → one AskUserQuestion, three questions (spec §2), each option's description leading with the
  `profile.mjs --cost` counts/minutes for that option; then re-render and the same A/B/C. *Other* →
  the `models` / `persist` / `unruled` question. Agent builds with `end` risk|everything chosen
  through B → *Walk it yourself before it lands?* (No recommended → no `walk=you`).
- Record `tests: <formatTests>` (and `target:` for agent builds) in the go-ahead commit; remove the
  Rush/Standard/Thorough question and §Customize; §Picking the profile ahead → §Picking the test plan
  ahead with the same mechanics; `--auto`/`--agent-walk` take the recommendation (`auto
  (recommended)`).
- `PLAN-FORMAT.md`: the `## Phases` table is the build's; the human sees slices (one line).

### Task 6 — `skills/build` (SKILL.md, EXECUTION.md): the levers drive the loop, always
- Read levers with `profile.mjs --levers` on **every** build (not only `--agent-walk`).
- `slice`: none → the implementer writes its tests, runs the type-check only; own → today's per-task
  rule; own+app → own + today's phase-close fast set; full → `gate.mjs <app>` after every task
  (quoted when unchanged). Phase close under none/own: no fast set — the ledger line says
  `gates deferred to the end (tests: slice=<v>)`.
- `review`: slice → today; app → one review of the phase's diff at its close; end → no task
  reviewer. The final whole-branch review always runs.
- Red stays a stop wherever it runs; a failure found later is dispatched against the slice the
  review names.
- `--here` keeps working; its levers come from `tests:` too (default the recommendation).

### Task 7 — `skills/verify`, `skills/agent-walk`, `skills/signoff`
- Replace the `verify:` / `testing:` lever text with `end`: none → `gate.mjs <apps> --typecheck`
  plus items 2, 4, 6 (the rest named skipped; first verdict line `nothing was tested (tests:
  end=none)`), touched → today's floors list, risk → today's full, everything → today's everything.
  Agent-walk: none|touched → no walk; risk → `[risk]` + cross-app; everything → full; `walk=you` →
  today's full+human. Signoff wording that names the old presets follows.
