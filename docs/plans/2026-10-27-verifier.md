# The verifier — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace builder's gate system with a per-repo background verifier — commit-tier tests beside the build, a phase-tier wait, a merge queue that runs everything on the merged result and fast-forwards the target — with failures judged by test identity, flakes listed automatically and every run isolated; then benchmark it against `main` on archived features.

**Architecture:** New modules under `scripts/verify/` (config, reports/adapters, ledger, classify, select, envpool, checkouts/land, run, schedule, serve, client), each pure or dependency-injected and tested alone; then the pipeline (build/verify/resume/agent-walk/plan/init skills, fleet, statusline, tidy, profile, dispatch, handoff, plan-slices) is moved onto it and `gate.mjs` / `gates-core.mjs` / `job.mjs` are removed; then a gate-replay harness and an end-to-end comparison measure it.

**Tech Stack:** Node 22 `.mjs`, no dependencies; `node:test`; git worktrees; `psql` for the Postgres pool; `xcrun simctl` / `xcresulttool` for iOS.

**Spec:** `docs/specs/2026-10-27-verifier-design.md` — read it first; this plan argues from it.

## Global Constraints

- No npm dependencies — builder is dropped into repos as a plugin (`scripts/config.mjs` header).
- Tests: `node --test 'scripts/test/*.test.mjs'`, Node's own runner; new test files are `scripts/test/verify-*.test.mjs`.
- All verifier state lives in `<main checkout>/.builder/verify/` (git-ignored via `.builder/.gitignore` = `*`).
- Work happens on branch `feat/verifier`. Nothing is merged to `main` until the benchmark (Part 4) is reported and the human approves.
- No consumer project names in any committed text (code, docs, CHANGELOG, fixtures) — say "a consuming project".
- Release is **6.0.0** (major — consumers migrate config). Version bump and CHANGELOG happen in the last task only, per `RELEASING.md`.
- When a change alters what a skill prints: `node preview/preview.mjs --check`, rewrite stale stages, `--stamp` them (`preview/README.md`).
- Client exit codes, used everywhere: `0` green · `1` red · `2` usage · `3` env-broken · `4` conflict · `5` gone · `6` cancelled · `75` pending.
- Test ID format: `<suite>::<repo-relative file>::<name path>` (name path joined with ` > `). Check IDs: `check::<name>`.
- Flake list clearance: 20 consecutive clean runs (`FLAKE_CLEAR = 20`).

## Review Focus

1. **A suite whose runner isn't installed in the run checkout** (no `node_modules` yet) — expected: `setup` runs first; if the command still exits without a report the suite is `env-broken` with the command's tail, never red, never a fix dispatch. (Task 8 test "no report → broken, retried once; still broken → env-broken, never red".)
2. **A test name containing regex characters or quotes** (`handles (a|b) in "x"`) — expected: single-test re-runs still select exactly that test; nothing breaks the shell. (Task 2 test "commands: files, whole suite, single-test grep escapes regex and quotes".)
3. **Two features landing on the same target at once** — expected: only one merge-tier run per target at a time; the second re-merges onto the new tip. (Task 9 test "one merge per target at a time"; Task 3 test "changedFiles and land: … refused when the target moved"; Task 12 test "a moved target exits 7".)
4. **A `compare: lines` check whose output carries timings** (`Done in 3.2s`) — expected: `match:` narrows to finding lines; without it, a line that differs only by a number still counts as new, so the config docs say to use `match`. (Task 1 test "normalizeVerify fills defaults and reads needs" parses `match`; Task 8 test "checks: exit compare, and lines compare uses match and the target output".)
5. **The service killed mid-run** — expected: on restart the request is re-queued and re-run, orphaned databases dropped, nothing lost. (Task 10 test "crash recovery: a request left running is re-queued and run".)

```js
// scripts/verify/config.mjs
/**
 * The verifier's config — the `verify:` block of `.claude/builder.md`'s frontmatter
 * (docs/specs/2026-10-27-verifier-design.md §Config).
 *
 * config.mjs's frontmatter parser reads one level of nesting; this block needs maps of maps and
 * one-line flow maps (`server: { runner: node-test, needs: [db] }`), so it has its own small
 * parser: indented maps, flow maps and lists, quoted scalars. Quote a flow value holding , : { } [ ].
 */
import { readFileSync, existsSync } from 'node:fs'
import { join } from 'node:path'

export const RUNNERS = ['node-test', 'vitest', 'jest', 'phpunit', 'xcodebuild', 'playwright', 'junit']
export const TIERS = ['commit', 'phase', 'merge']

/** A trailing ` # comment`, outside quotes, removed. */
export function stripComment(line) {
  let q = null
  for (let i = 0; i < line.length; i++) {
    const c = line[i]
    if (q) {
      if (c === q) q = null
      continue
    }
    if (c === '"' || c === "'") q = c
    else if (c === '#' && (i === 0 || /\s/.test(line[i - 1]))) return line.slice(0, i).trimEnd()
  }
  return line.trimEnd()
}

const scalar = (s) => {
  const t = s.trim()
  if (/^"[\s\S]*"$/.test(t)) return t.slice(1, -1).replace(/\\"/g, '"')
  if (/^'[\s\S]*'$/.test(t)) return t.slice(1, -1).replace(/''/g, "'")
  if (t === 'true') return true
  if (t === 'false') return false
  if (t === '' || t === '~' || t === 'null') return null
  if (/^-?\d+(\.\d+)?$/.test(t)) return Number(t)
  return t
}

/** `{ a: 1, b: [x, { c: d }] }`, `[a, b]`, or a scalar. */
export function parseFlow(src) {
  let i = 0
  const ws = () => {
    while (i < src.length && /\s/.test(src[i])) i++
  }
  const atom = (stops) => {
    ws()
    const start = i
    if (src[i] === '"' || src[i] === "'") {
      const q = src[i++]
      while (i < src.length && src[i] !== q) i++
      i++
      return scalar(src.slice(start, i))
    }
    while (i < src.length && !stops.includes(src[i])) i++
    return scalar(src.slice(start, i))
  }
  const value = () => {
    ws()
    if (src[i] === '{') return map()
    if (src[i] === '[') return list()
    return atom(',}]')
  }
  const map = () => {
    i++
    const out = {}
    for (;;) {
      ws()
      if (src[i] === '}') {
        i++
        return out
      }
      const key = String(atom(':}'))
      if (src[i] !== ':') throw new Error(`expected ':' after "${key}" in ${src}`)
      i++
      out[key] = value()
      ws()
      if (src[i] === ',') {
        i++
        continue
      }
      if (src[i] === '}') {
        i++
        return out
      }
      throw new Error(`expected ',' or '}' in ${src}`)
    }
  }
  const list = () => {
    i++
    const out = []
    for (;;) {
      ws()
      if (src[i] === ']') {
        i++
        return out
      }
      out.push(value())
      ws()
      if (src[i] === ',') {
        i++
        continue
      }
      if (src[i] === ']') {
        i++
        return out
      }
      throw new Error(`expected ',' or ']' in ${src}`)
    }
  }
  const v = value()
  ws()
  if (i < src.length) throw new Error(`unexpected "${src.slice(i)}" in ${src}`)
  return v
}

/** Indented `key: value` lines → nested maps; a value opening with { or [ is a flow value. */
export function parseBlock(lines) {
  const rows = lines
    .map(stripComment)
    .filter((l) => l.trim())
    .map((l) => ({ indent: l.length - l.trimStart().length, body: l.trim() }))
  let i = 0
  const map = (indent) => {
    const out = {}
    while (i < rows.length && rows[i].indent >= indent) {
      const { body, indent: at } = rows[i]
      if (at > indent) throw new Error(`unexpected indentation at "${body}"`)
      const kv = /^([A-Za-z_][\w.-]*):(?:\s+(.*))?$/.exec(body)
      if (!kv) throw new Error(`expected "key: value" at "${body}"`)
      i++
      const raw = (kv[2] ?? '').trim()
      if (raw === '') out[kv[1]] = i < rows.length && rows[i].indent > at ? map(rows[i].indent) : null
      else out[kv[1]] = /^[{[]/.test(raw) ? parseFlow(raw) : scalar(raw)
    }
    return out
  }
  return rows.length ? map(rows[0].indent) : {}
}

/** The lines under `verify:` in a config's frontmatter, or null when there is none. */
export function verifyLines(text) {
  const m = /^---\n([\s\S]*?)\n---/.exec(text)
  if (!m) return null
  const lines = m[1].split('\n')
  const at = lines.findIndex((l) => /^verify:\s*(#.*)?$/.test(l))
  if (at < 0) return null
  const out = []
  for (const l of lines.slice(at + 1)) {
    if (l.trim() && !/^\s/.test(l) && !l.startsWith('#')) break
    out.push(l)
  }
  return out
}

export function durationMs(v, fallback) {
  if (v == null) return fallback
  if (typeof v === 'number') return v * 1000
  const m = /^(\d+)\s*(ms|s|m|h)$/.exec(String(v))
  if (!m) throw new Error(`"${v}" is not a duration (e.g. 90s, 15m)`)
  return Number(m[1]) * { ms: 1, s: 1000, m: 60000, h: 3600000 }[m[2]]
}

const list = (v) => (v == null ? [] : Array.isArray(v) ? v : [v])
const tiersOf = (v, dflt, where) => {
  const t = v == null ? dflt : list(v)
  for (const x of t) if (!TIERS.includes(x)) throw new Error(`${where}: tier "${x}" is not one of ${TIERS.join(', ')}`)
  return t
}
const needOf = (n, where) => {
  if (n === 'db' || n === 'walk-env' || n === 'simulator') return { kind: n }
  if (n && typeof n === 'object' && Array.isArray(n.ports)) return { kind: 'ports', names: n.ports.map(String) }
  if (typeof n === 'string' && n) return { kind: 'hook', name: n }
  throw new Error(`${where}: can't read need ${JSON.stringify(n)}`)
}

export function normalizeVerify(raw) {
  const r = raw ?? {}
  const suites = Object.entries(r.suites ?? {}).map(([name, s]) => {
    const where = `verify.suites.${name}`
    if (!s || typeof s !== 'object') throw new Error(`${where}: expected a map`)
    if (!RUNNERS.includes(s.runner)) throw new Error(`${where}: runner "${s.runner}" is not one of ${RUNNERS.join(', ')}`)
    if (s.runner === 'junit' && (!s.command || !s.report)) throw new Error(`${where}: a junit suite needs command (with {files}) and report`)
    if (s.runner === 'xcodebuild' && (!s.scheme || !s.target)) throw new Error(`${where}: an xcodebuild suite needs scheme and target`)
    return {
      name,
      runner: s.runner,
      files: s.files ?? null,
      app: s.app ?? null,
      cwd: s.cwd ?? '.',
      args: s.args ?? '',
      needs: list(s.needs).map((n) => needOf(n, where)),
      tiers: tiersOf(s.tiers, TIERS, where),
      command: s.command ?? null,
      report: s.report ?? null,
      scheme: s.scheme ?? null,
      target: s.target ?? null,
      destination: s.destination ?? null,
    }
  })
  const checks = Object.entries(r.checks ?? {}).map(([name, c]) => {
    const where = `verify.checks.${name}`
    if (!c?.run) throw new Error(`${where}: needs run`)
    const compare = c.compare ?? 'exit'
    if (!['exit', 'lines'].includes(compare)) throw new Error(`${where}: compare is exit or lines`)
    return { name, run: String(c.run), cwd: c.cwd ?? '.', compare, match: c.match ?? null, tiers: tiersOf(c.tiers, ['phase', 'merge'], where), needs: list(c.needs).map((n) => needOf(n, where)) }
  })
  if (!suites.length && !checks.length) throw new Error('verify: declares no suites and no checks')
  const db = r.db ? { kind: r.db.kind ?? 'postgres', url: r.db.url, env: list(r.db.env ?? 'DATABASE_URL'), inputs: list(r.db.inputs), prepare: r.db.prepare ?? null, max: r.db.max ?? 4 } : null
  if (db && (db.kind !== 'postgres' || !db.url)) throw new Error('verify.db: kind postgres with a url')
  const all = [...suites, ...checks]
  if (all.some((x) => x.needs.some((n) => n.kind === 'db')) && !db) throw new Error('verify: a suite needs db but verify.db is not set')
  if (all.some((x) => x.needs.some((n) => n.kind === 'simulator')) && !r.simulator) throw new Error('verify: a suite needs simulator but verify.simulator is not set')
  if (all.some((x) => x.needs.some((n) => n.kind === 'hook')) && !r.env?.lease) throw new Error('verify: a suite needs a hook resource but verify.env.lease is not set')
  const workers = r.workers ?? 2
  return {
    workers,
    timeoutMs: durationMs(r.timeout, 15 * 60000),
    setup: r.setup ?? null,
    setupInputs: list(r.setup_inputs ?? ['package-lock.json', 'pnpm-lock.yaml', 'yarn.lock', 'composer.lock', 'Podfile.lock']),
    db,
    simulator: r.simulator ? { base: String(r.simulator.base), max: r.simulator.max ?? 2 } : null,
    env: r.env ? { lease: r.env.lease ?? null, release: r.env.release ?? null, max: r.env.max ?? workers } : null,
    suites,
    checks,
  }
}

export function loadVerify(root) {
  const p = join(root, '.claude', 'builder.md')
  if (!existsSync(p)) return { ok: false, reason: 'no .claude/builder.md — run /builder:init' }
  const lines = verifyLines(readFileSync(p, 'utf8'))
  if (!lines) return { ok: false, reason: '.claude/builder.md has no verify: block — run /builder:init --update' }
  try {
    return { ok: true, verify: normalizeVerify(parseBlock(lines)) }
  } catch (e) {
    return { ok: false, reason: e.message }
  }
}
```

```js
/**
 * Test reports → Result rows `{ file, name, status: pass|fail|skip, ms, msg }`. `file` is relative
 * to `root` (the suite's cwd) when the report holds absolute paths.
 */
const ENT = { amp: '&', lt: '<', gt: '>', quot: '"', apos: "'" }
const decode = (s) => s.replace(/&(#x?[0-9a-f]+|\w+);/gi, (m, e) => (e[0] === '#' ? String.fromCodePoint(e[1] === 'x' || e[1] === 'X' ? parseInt(e.slice(2), 16) : Number(e.slice(1))) : ENT[e] ?? m))
const attrs = (s) => {
  const o = {}
  for (const m of s.matchAll(/([\w:-]+)\s*=\s*"([^"]*)"/g)) o[m[1]] = decode(m[2])
  return o
}
export const rel = (f, root) => (root && f && f.startsWith(`${root}/`) ? f.slice(root.length + 1) : f ?? '')
const clip = (s) => (s ? String(s).trim().slice(0, 2000) : null)

/** JUnit XML. A case's file: its `file`, else its suite's `file`, else `classname`, else the suite's name. */
export function parseJUnit(xml, { root = null } = {}) {
  const out = []
  let suite = {}
  for (const m of xml.matchAll(/<testsuite\b([^>]*)>|<testcase\b([^>]*?)(\/>|>([\s\S]*?)<\/testcase>)/g)) {
    if (m[1] !== undefined) {
      suite = attrs(m[1])
      continue
    }
    const a = attrs(m[2])
    const body = m[4] ?? ''
    const fail = /<(failure|error)\b([^>]*?)(\/>|>([\s\S]*?)<\/\1>)/.exec(body)
    const status = fail ? 'fail' : /<skipped\b/.test(body) ? 'skip' : 'pass'
    const msg = fail ? clip(decode([attrs(fail[2]).message, fail[4]].filter(Boolean).join('\n'))) : null
    out.push({ file: rel(a.file ?? suite.file ?? a.classname ?? suite.name, root), name: a.name ?? '', status, ms: Math.round(Number(a.time ?? 0) * 1000), msg })
  }
  return out
}

/** `jest --json`. */
export function parseJestJson(text, { root = null } = {}) {
  const j = JSON.parse(text)
  return (j.testResults ?? []).flatMap((f) =>
    (f.assertionResults ?? []).map((a) => ({
      file: rel(f.name ?? f.testFilePath, root),
      name: a.fullName ?? a.title,
      status: a.status === 'passed' ? 'pass' : a.status === 'failed' ? 'fail' : 'skip',
      ms: a.duration ?? 0,
      msg: a.failureMessages?.length ? clip(a.failureMessages.join('\n')) : null,
    })),
  )
}

/** `xcrun xcresulttool get test-results tests --format json`: a test's file is its class + `.swift`. */
export function parseXcresult(text) {
  const out = []
  const walk = (n, cls) => {
    if (n.nodeType === 'Test Case') {
      const msgs = (n.children ?? []).filter((c) => c.nodeType === 'Failure Message').map((c) => c.name)
      const status = /^(Passed|Expected Failure)$/.test(n.result) ? 'pass' : n.result === 'Skipped' ? 'skip' : 'fail'
      out.push({ file: cls ? `${cls}.swift` : '', name: n.name, status, ms: Math.round((n.durationInSeconds ?? 0) * 1000), msg: msgs.join('\n') || null })
      return
    }
    for (const c of n.children ?? []) walk(c, n.nodeType === 'Test Suite' ? n.name : cls)
  }
  for (const n of JSON.parse(text).testNodes ?? []) walk(n, null)
  return out
}

/** One JSON Result per line (node-reporter.mjs). */
export const parseJsonLines = (text, { root = null } = {}) =>
  text
    .split('\n')
    .filter(Boolean)
    .map((l) => JSON.parse(l))
    .map((r) => ({ ...r, file: rel(r.file, root) }))
```

```js
// scripts/verify/node-reporter.mjs
/**
 * A node:test reporter writing one Result per test as a JSON line: file, name path (describe
 * names joined with ' > '), status, ms, msg. Node's own junit reporter does not say which file a
 * test lives in, and the verifier needs that to re-run one test and to know whether a branch owns it.
 */
export default async function* reporter(source) {
  const stacks = new Map() // file → [name at each nesting]
  for await (const ev of source) {
    const d = ev.data ?? {}
    const file = d.file ?? ''
    const stack = stacks.get(file) ?? stacks.set(file, []).get(file)
    if (ev.type === 'test:start') {
      stack[d.nesting] = d.name
      stack.length = d.nesting + 1
      continue
    }
    if (ev.type !== 'test:pass' && ev.type !== 'test:fail') continue
    if (d.details?.type === 'suite') continue
    const err = d.details?.error
    yield JSON.stringify({
      file,
      name: [...stack.slice(0, d.nesting), d.name].join(' > '),
      status: ev.type === 'test:fail' ? 'fail' : d.skip || d.todo ? 'skip' : 'pass',
      ms: Math.round(d.details?.duration_ms ?? 0),
      msg: err ? String(err.cause?.stack ?? err.cause ?? err.message ?? err).slice(0, 2000) : null,
    }) + '\n'
  }
}
```

```js
// scripts/verify/checkouts.mjs
/**
 * Run checkouts — the clean copies a worker tests, never the agent's live worktree (spec §The
 * units) — and landing: the merge queue fast-forwards the target to exactly the commit it tested.
 */
import { existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs'
import { join } from 'node:path'
import { createHash } from 'node:crypto'
import { git, tryGit, sh } from './git.mjs'
import { checkedOutBranch } from '../config.mjs'

export const checkoutsDir = (root) => join(root, '.builder', 'verify', 'co')

export function ensureCheckout(root, slot) {
  const path = join(checkoutsDir(root), String(slot))
  if (!existsSync(join(path, '.git'))) {
    mkdirSync(checkoutsDir(root), { recursive: true })
    tryGit(root, 'worktree', 'prune')
    git(root, 'worktree', 'add', '--detach', '-f', path, 'HEAD')
  }
  return path
}

export const commitExists = (root, sha) => tryGit(root, 'cat-file', '-e', `${sha}^{commit}`) !== null

/** Move a checkout to `sha`: forced, detached, untracked files gone (ignored ones — node_modules — kept). */
export function checkoutAt(path, sha) {
  tryGit(path, 'merge', '--abort')
  git(path, 'checkout', '-q', '--detach', '--force', sha)
  git(path, 'clean', '-fdq')
  return git(path, 'rev-parse', 'HEAD')
}

export function mergedCheckout(path, targetSha, branchSha, message) {
  checkoutAt(path, targetSha)
  if (tryGit(path, 'merge', '--no-ff', '-m', message, branchSha) !== null) return { sha: git(path, 'rev-parse', 'HEAD') }
  const files = (tryGit(path, 'diff', '--name-only', '--diff-filter=U') ?? '').split('\n').filter(Boolean)
  tryGit(path, 'merge', '--abort')
  return { conflict: true, files }
}

/** `verify.setup` in this checkout when its inputs (lockfiles by default) changed since it last ran. */
export function setupIfNeeded(path, verify, run = (cmd) => sh(cmd, { cwd: path })) {
  if (!verify.setup) return false
  const h = createHash('sha256').update(tryGit(path, 'ls-files', '-s', '--', ...verify.setupInputs) ?? '').update(verify.setup).digest('hex')
  const mark = `${path}.setup`
  if (existsSync(mark) && readFileSync(mark, 'utf8') === h) return false
  run(verify.setup)
  writeFileSync(mark, h)
  return true
}

export const changedFiles = (root, from, to) => (tryGit(root, 'diff', '--name-only', from, to) ?? '').split('\n').filter(Boolean)

/** Fast-forward `target` to `tested` only if it still points at `expectedOld`. */
export function land(root, target, tested, expectedOld) {
  const cur = tryGit(root, 'rev-parse', `refs/heads/${target}`)
  if (cur !== expectedOld) return { ok: false, reason: `${target} moved (${cur?.slice(0, 7)} is not ${expectedOld.slice(0, 7)})` }
  if (checkedOutBranch(root) === target) {
```

```js
// scripts/verify/ledger.mjs
/**
 * Everything the verifier knows, as files under <main checkout>/.builder/verify/ (spec §The
 * ledgers): every test result, the target's known failures by test ID, the flake list, the
 * requests with their verdicts, and the target's output lines for `compare: lines` checks.
 * Writes are atomic (temp + rename); the service and the clients share them without locks — a
 * request file is written by one client, then only by the service.
 */
import { existsSync, mkdirSync, readFileSync, writeFileSync, renameSync, appendFileSync, readdirSync } from 'node:fs'
import { join } from 'node:path'
import { randomBytes } from 'node:crypto'

export const FLAKE_CLEAR = 20
export const verifyDir = (root) => join(root, '.builder', 'verify')

const readJson = (p, d) => {
  try {
    return JSON.parse(readFileSync(p, 'utf8'))
  } catch {
    return d
  }
}
const writeJson = (p, v) => {
  const t = `${p}.${process.pid}.${randomBytes(2).toString('hex')}.tmp`
  writeFileSync(t, JSON.stringify(v, null, 2) + '\n')
  renameSync(t, p)
}

export function openLedger(root) {
  const dir = verifyDir(root)
  mkdirSync(join(dir, 'requests'), { recursive: true })
  const ignore = join(root, '.builder', '.gitignore')
  if (!existsSync(ignore)) writeFileSync(ignore, '*\n')
  const P = {
    results: join(dir, 'results.jsonl'),
    known: join(dir, 'known-failures.json'),
    flakes: join(dir, 'flakes.json'),
    req: (id) => join(dir, 'requests', `${id}.json`),
    lines: (sha, name) => join(dir, 'lines', sha, `${name}.txt`),
  }

  const requests = (filter = () => true) =>
    readdirSync(join(dir, 'requests'))
      .filter((f) => f.endsWith('.json'))
      .map((f) => readJson(join(dir, 'requests', f), null))
      .filter(Boolean)
      .filter(filter)
      .sort((a, b) => a.createdAt.localeCompare(b.createdAt) || a.id.localeCompare(b.id))

  const editKnown = (target, fn) => {
    const all = readJson(P.known, {})
    const cur = all[target] ?? { sha: null, ids: [] }
    all[target] = { sha: cur.sha, ids: [...fn(new Set(cur.ids))].sort() }
    writeJson(P.known, all)
  }

  return {
    dir,
    appendResults(rows) {
      if (rows.length) appendFileSync(P.results, rows.map((r) => JSON.stringify(r)).join('\n') + '\n')
    },
    resultsAt(sha) {
      const m = new Map()
      if (!existsSync(P.results)) return m
      for (const l of readFileSync(P.results, 'utf8').split('\n')) {
        if (!l) continue
        const r = JSON.parse(l)
        if (r.sha === sha) m.set(r.id, r.status)
      }
      return m
    },
    known(target) {
      const k = readJson(P.known, {})[target]
      return { sha: k?.sha ?? null, ids: new Set(k?.ids ?? []) }
    },
    setKnown(target, sha, ids) {
      const all = readJson(P.known, {})
      all[target] = { sha, ids: [...ids].sort() }
      writeJson(P.known, all)
    },
    addKnown: (target, ids) => editKnown(target, (s) => (ids.forEach((i) => s.add(i)), s)),
    removeKnown: (target, ids) => editKnown(target, (s) => (ids.forEach((i) => s.delete(i)), s)),
    flakes: () => readJson(P.flakes, {}),
    isFlaky: (id) => Boolean(readJson(P.flakes, {})[id]),
    recordFlip(id) {
      const all = readJson(P.flakes, {})
      const f = all[id] ?? { since: new Date().toISOString(), flips: 0, cleanStreak: 0 }
      all[id] = { ...f, flips: f.flips + 1, cleanStreak: 0 }
      writeJson(P.flakes, all)
    },
    recordClean(ids) {
      const all = readJson(P.flakes, {})
      let changed = false
      for (const id of ids) {
        if (!all[id]) continue
        changed = true
        all[id].cleanStreak += 1
        if (all[id].cleanStreak >= FLAKE_CLEAR) delete all[id]
      }
      if (changed) writeJson(P.flakes, all)
    },
    newRequest(fields) {
      const id = `${Date.now().toString(36)}-${randomBytes(3).toString('hex')}`
      const req = { id, state: 'queued', createdAt: new Date().toISOString(), ...fields }
      writeJson(P.req(id), req)
      return req
    },
    saveRequest: (req) => writeJson(P.req(req.id), req),
    getRequest: (id) => readJson(P.req(id), null),
    requests,
    verdictFor(branch, sha = null) {
      const done = requests((r) => r.branch === branch && r.state === 'done' && r.verdict && (!sha || r.sha === sha))
      return done.at(-1)?.verdict ?? null
    },
    lastGreen(branch, tiers = ['commit', 'phase']) {
      return requests((r) => r.branch === branch && r.state === 'done' && tiers.includes(r.tier) && r.verdict?.status === 'green').at(-1) ?? null
    },
    readLines(sha, name) {
      const p = P.lines(sha, name)
      return existsSync(p) ? new Set(readFileSync(p, 'utf8').split('\n').filter(Boolean)) : null
    },
    writeLines(sha, name, lines) {
      mkdirSync(join(dir, 'lines', sha), { recursive: true })
      writeFileSync(P.lines(sha, name), [...lines].join('\n') + '\n')
    },
  }
}
```

```js
// scripts/verify/classify.mjs
/**
 * One failing test → what it means (spec §Judging a failure), the cheapest question first; at most
 * one single-test run per question, never a suite re-run. Only `regression` dispatches a fix.
 * (A run with no report at all is env-broken — decided by the runner before anything gets here.)
 */
export async function classify(f, ctx) {
  if (ctx.known.has(f.id)) return { kind: 'known' }
  if (ctx.isFlaky(f.id)) return { kind: 'flake', listed: true }
  if ((await ctx.rerunHere(f)) === 'pass') return ctx.branchOwns(f.file) ? { kind: 'regression', note: 'flaky test this branch owns' } : { kind: 'flake', listed: false }
  if ((await ctx.rerunOnTarget(f)) === 'fail') return { kind: 'debt' }
  return { kind: 'regression' }
}
```

```js
// scripts/verify/select.mjs
/**
 * Which test files a commit range can reach, per suite — impact.mjs's import graph, which already
 * knows schema readers, workspace packages, co-changed specs and the changes it can't see past.
 */
import { posix } from 'node:path'
import { impactOf, scopeTests } from '../impact.mjs'

export function selectSuites(checkout, base, suites) {
  let impact = null
  const out = {}
  for (const s of suites) {
    if (!s.files) {
      out[s.name] = { files: 'all', why: 'the suite names no file glob' }
      continue
    }
    impact ??= impactOf(checkout, { since: base })
    const r = scopeTests(impact, s.files)
    out[s.name] = r.mode === 'whole' ? { files: 'all', why: r.reason } : r.mode === 'none' ? { files: [], why: r.reason } : { files: r.tests, why: r.why }
  }
  return out
}

export const fromCwd = (cwd, files) => files.map((f) => (cwd === '.' ? f : posix.relative(cwd, f)))
```

```js
// scripts/verify/envpool.mjs
/**
 * Isolated environments (spec §Environments): a Postgres database cloned from a template per
 * lease, free ports by name, a cloned simulator, the walk env (one at a time), and project hooks
 * for anything else. Capacity is counted here; a lease the pool can't grant now returns null.
 */
import { createServer } from 'node:net'
import { createHash } from 'node:crypto'
import { execFileSync } from 'node:child_process'
import { sh as shell } from './git.mjs'

export const freePort = () =>
  new Promise((res, rej) => {
    const s = createServer()
    s.unref()
    s.on('error', rej)
    s.listen(0, () => {
      const { port } = s.address()
      s.close(() => res(port))
    })
  })

export const psql = (url, sql) => execFileSync('psql', [url, '-v', 'ON_ERROR_STOP=1', '-tAc', sql], { encoding: 'utf8', stdio: ['ignore', 'pipe', 'pipe'] }).trim()

export const inputsHash = (checkout, globs) => createHash('sha256').update(execFileSync('git', ['ls-files', '-s', '--', ...globs], { cwd: checkout, encoding: 'utf8' })).digest('hex')

const dbName = (url) => decodeURIComponent(new URL(url).pathname.slice(1))
const withDb = (url, name) => {
  const u = new URL(url)
  u.pathname = `/${name}`
  return u.toString()
}

export function createPool(verify, { sh = shell, psql: pg = psql, ports = freePort } = {}) {
  const used = { db: 0, simulator: 0, 'walk-env': 0, hook: 0 }
  const cap = { db: verify.db?.max ?? 0, simulator: verify.simulator?.max ?? 0, 'walk-env': 1, hook: verify.env?.max ?? verify.workers }
  const counted = (needs) => needs.map((n) => n.kind).filter((k) => k in used)
  const base = verify.db ? dbName(verify.db.url) : null
  let seq = 0

  const pool = {
    canLease(needs) {
      const want = {}
      for (const k of counted(needs)) want[k] = (want[k] ?? 0) + 1
      return Object.entries(want).every(([k, n]) => used[k] + n <= cap[k])
    },
    async lease(needs, { template = null, cwd } = {}) {
      if (!pool.canLease(needs)) return null
      for (const k of counted(needs)) used[k]++
      const env = {}
      const undo = []
      const unwind = () => {
        for (const u of undo.reverse()) {
          try {
            u()
          } catch {}
        }
        for (const k of counted(needs)) used[k]--
      }
      try {
        for (const n of needs) {
          if (n.kind === 'db') {
            const name = `${base}_vt_${process.pid}_${++seq}`
            pg(verify.db.url, `CREATE DATABASE "${name}" TEMPLATE "${template}"`)
            undo.push(() => pg(verify.db.url, `DROP DATABASE IF EXISTS "${name}" WITH (FORCE)`))
            for (const v of verify.db.env) env[v] = withDb(verify.db.url, name)
          } else if (n.kind === 'ports') {
            for (const v of n.names) env[v] = String(await ports())
          } else if (n.kind === 'simulator') {
            const udid = sh(`xcrun simctl clone ${JSON.stringify(verify.simulator.base)} vt-${process.pid}-${++seq}`, { cwd }).trim()
            undo.push(() => sh(`xcrun simctl delete ${udid}`, { cwd }))
            env.SIMULATOR_UDID = udid
          } else if (n.kind === 'hook') {
            const out = sh(verify.env.lease, { cwd, env: { ...process.env, BUILDER_NEED: n.name } })
            const pairs = Object.fromEntries(
              out
                .split('\n')
                .map((l) => /^([A-Za-z_]\w*)=(.*)$/.exec(l.trim()))
                .filter(Boolean)
                .map((m) => [m[1], m[2]]),
            )
            Object.assign(env, pairs)
            if (verify.env.release) undo.push(() => sh(verify.env.release, { cwd, env: { ...process.env, ...pairs, BUILDER_NEED: n.name } }))
          }
          // walk-env: an exclusive slot; the env vars are agent_walk's, added by the service.
        }
      } catch (e) {
        unwind()
        throw e
      }
      let released = false
      return {
        env,
        release() {
          if (released) return
          released = true
          unwind()
        },
      }
    },
    templateName: (hash) => `${base}_vt_tpl_${hash.slice(0, 12)}`,
    ensureTemplate(checkout, hash) {
      const tpl = pool.templateName(hash)
      if (pg(verify.db.url, `SELECT 1 FROM pg_database WHERE datname = '${tpl}'`) === '1') return tpl
      const building = `${tpl}_building`
      pg(verify.db.url, `DROP DATABASE IF EXISTS "${building}" WITH (FORCE)`)
      pg(verify.db.url, `CREATE DATABASE "${building}"`)
      try {
        if (verify.db.prepare) sh(verify.db.prepare, { cwd: checkout, env: { ...process.env, ...Object.fromEntries(verify.db.env.map((v) => [v, withDb(verify.db.url, building)])) } })
        pg(verify.db.url, `ALTER DATABASE "${building}" RENAME TO "${tpl}"`)
      } catch (e) {
        pg(verify.db.url, `DROP DATABASE IF EXISTS "${building}" WITH (FORCE)`)
        throw e
      }
      return tpl
    },
    dropOrphans() {
      if (!verify.db) return []
      const names = pg(verify.db.url, `SELECT datname FROM pg_database WHERE datname LIKE '${base}\\_vt\\_%' AND datname NOT LIKE '${base}\\_vt\\_tpl\\_%'`)
        .split('\n')
        .filter(Boolean)
      for (const n of names) pg(verify.db.url, `DROP DATABASE IF EXISTS "${n}" WITH (FORCE)`)
      return names
    },
  }
  return pool
}
```

```js
// scripts/verify/run.mjs
/**
 * One request, in one checkout → its verdict (spec §The flow, §Judging a failure). Checks first,
 * then each suite's selected files (all of them at the merge tier); every failing test is judged by
 * classify(); a run with no report is retried once in a fresh lease and is env-broken after that.
 */
import { existsSync, readFileSync, mkdirSync, rmSync } from 'node:fs'
import { join, posix } from 'node:path'
import { spawn } from 'node:child_process'
import { ADAPTERS } from './adapters.mjs'
import { classify } from './classify.mjs'
import { fromCwd } from './select.mjs'
import { inputsHash } from './envpool.mjs'

export function runShell(cmd, { cwd, env = process.env, timeoutMs = 0, signal = null } = {}) {
  return new Promise((resolve) => {
    // An already-aborted signal never fires 'abort': a cancelled run starts nothing more.
    if (signal?.aborted) return resolve({ code: 1, timedOut: false, out: 'cancelled' })
    const p = spawn('/bin/bash', ['-c', cmd], { cwd, env, detached: true, stdio: ['ignore', 'pipe', 'pipe'] })
    let out = ''
    const add = (b) => {
      out = (out + b).slice(-20000)
    }
    p.stdout.on('data', add)
    p.stderr.on('data', add)
    let timedOut = false
    const kill = () => {
      try {
        process.kill(-p.pid, 'SIGKILL')
      } catch {}
    }
    const t = timeoutMs ? setTimeout(() => ((timedOut = true), kill()), timeoutMs) : null
    signal?.addEventListener('abort', kill, { once: true })
    p.on('close', (code) => {
      if (t) clearTimeout(t)
      resolve({ code: code ?? 1, timedOut, out })
    })
  })
}

export const testId = (suite, r) => `${suite}::${r.file}::${r.name}`

export async function bisect(regs, commits, { atCommit, statusAt }) {
  for (const g of regs) g.introducedBy = null
  for (const sha of commits) {
    const open = regs.filter((g) => !g.introducedBy)
    if (!open.length) break
    await atCommit(sha)
    for (const g of open) if ((await statusAt(g)) === 'fail') g.introducedBy = sha
  }
  for (const g of regs) g.introducedBy ??= commits.at(-1)
}

const linesOf = (out, match) => {
  const re = match ? new RegExp(match) : null
  return new Set(
    out
      .split('\n')
      .map((l) => l.trim())
      .filter((l) => l && (!re || re.test(l))),
  )
}

export async function runRequest(req, ctx) {
  const { verify, pool, ledger, checkout, signal } = ctx
  const t0 = Date.now()
  const verdict = { request: req.id, branch: req.branch, sha: req.sha, tier: req.tier, status: 'green', regressions: [], flakes: [], known: [], debt: [], broken: [], selection: {}, reused: 0, ms: 0 }
  const rows = []
  const tmp = join(ledger.dir, 'reports', req.id)
  mkdirSync(tmp, { recursive: true })
  let n = 0
  const known = ledger.known(req.target).ids
  const owns = req.changed ?? []
  const branchOwns = (file) => Boolean(file) && owns.some((c) => c === file || c.endsWith(`/${file}`) || file.endsWith(`/${c}`))
  const env = (lease) => ({ ...process.env, ...(ctx.baseEnv ?? {}), ...lease.env })
  const templateFor = (needs, where) => (needs.some((x) => x.kind === 'db') ? pool.ensureTemplate(where, inputsHash(where, verify.db.inputs)) : null)

  const runSuite = async (suite, files, { where = checkout, grep = null } = {}) => {
    const adapter = ADAPTERS[suite.runner]
    const cwd = join(where, suite.cwd)
    const report = adapter.reportPath ? adapter.reportPath(suite, cwd) : join(tmp, `${++n}-${suite.name}.out`)
    rmSync(report, { force: true })
    const lease = await ctx.lease(suite.needs, { template: templateFor(suite.needs, where), cwd })
    try {
      const cmd = adapter.command({ suite, files: files === 'all' ? null : fromCwd(suite.cwd, files), grep, report })
      const r = await runShell(cmd, { cwd, env: env(lease), timeoutMs: verify.timeoutMs, signal })
      if (!existsSync(report)) return { results: null, reason: r.timedOut ? `timed out after ${Math.round(verify.timeoutMs / 60000)}m with no report` : `no report (exit ${r.code}): ${r.out.slice(-400)}` }
      const results = adapter.parse(readFileSync(report, 'utf8'), { root: cwd })
      if (!results.length && r.code !== 0) return { results: null, reason: `exit ${r.code} with an empty report: ${r.out.slice(-400)}` }
      return { results: results.map((x) => ({ ...x, file: suite.cwd === '.' ? x.file : posix.join(suite.cwd, x.file) })) }
    } finally {
      lease.release()
    }
  }
  const statusIn = (res, f) => (res.results ? res.results.find((x) => x.file === f.file && x.name === f.name)?.status ?? 'missing' : 'broken')
  const rerun = async (suite, f, where) => statusIn(await runSuite(suite, [f.file], { where, grep: f.name }), f)

  const runCheck = async (c, where) => {
    const cwd = join(where, c.cwd)
    const lease = await ctx.lease(c.needs, { template: templateFor(c.needs, where), cwd })
    try {
      return await runShell(c.run, { cwd, env: env(lease), timeoutMs: verify.timeoutMs, signal })
    } finally {
      lease.release()
    }
  }
  const targetLines = async (c) => {
    const cached = ledger.readLines(ctx.targetSha, c.name)
    if (cached) return cached
    const s = linesOf((await runCheck(c, await ctx.targetCheckout())).out, c.match)
    ledger.writeLines(ctx.targetSha, c.name, s)
    return s
  }
  const checkFails = async (c, where) => {
    const r = await runCheck(c, where)
    if (r.timedOut) return { fail: true, msg: `timed out after ${Math.round(verify.timeoutMs / 60000)}m` }
    if (c.compare === 'exit') return { fail: r.code !== 0, msg: r.out.slice(-1500) }
    const theirs = await targetLines(c)
    const fresh = [...linesOf(r.out, c.match)].filter((l) => !theirs.has(l))
    return { fail: fresh.length > 0, msg: fresh.slice(0, 30).join('\n') }
  }

  const record = (f, k, suiteName) => {
    if (k.kind === 'known') verdict.known.push(f.id)
    else if (k.kind === 'flake') {
      verdict.flakes.push(f.id)
      if (!k.listed) ledger.recordFlip(f.id)
    } else if (k.kind === 'debt') {
      verdict.debt.push(f.id)
      ledger.addKnown(req.target, [f.id])
    } else verdict.regressions.push({ suite: suiteName, id: f.id, file: f.file, name: f.name, msg: f.msg, ...(k.note && { note: k.note }), introducedBy: null })
  }
  const judge = (f, rerunHere, rerunOnTarget) => classify(f, { known, isFlaky: ledger.isFlaky, branchOwns, rerunHere, rerunOnTarget })

  // 1. Checks.
  const checksRun = new Map()
  for (const c of verify.checks.filter((x) => x.tiers.includes(req.tier))) {
    if (signal?.aborted) break
    const r = await checkFails(c, checkout)
    if (signal?.aborted) break
    const id = `check::${c.name}`
    rows.push({ id, status: r.fail ? 'fail' : 'pass' })
    if (!r.fail) continue
    checksRun.set(id, c)
    const f = { id, file: null, name: c.name, msg: r.msg }
    record(
      f,
      await judge(
        f,
        async () => ((await checkFails(c, checkout)).fail ? 'fail' : 'pass'),
        async () => (c.compare === 'lines' ? 'pass' : (await checkFails(c, await ctx.targetCheckout())).fail ? 'fail' : 'pass'),
      ),
      'check',
    )
  }

  // 2. Suites.
  const suites = verify.suites.filter((s) => s.tiers.includes(req.tier))
  const sel = req.tier === 'merge' ? Object.fromEntries(suites.map((s) => [s.name, { files: 'all', why: 'merge tier: the whole suite' }])) : ctx.select(checkout, req.base, suites)
  const prior = req.tier === 'phase' ? ledger.resultsAt(req.sha) : new Map()
  const suiteOf = new Map(suites.map((s) => [s.name, s]))
  for (const s of suites) {
    if (signal?.aborted) break
    let { files, why } = sel[s.name]
    if (Array.isArray(files) && prior.size) {
      const greenFile = (file) => {
        const mine = [...prior].filter(([id]) => id.startsWith(`${s.name}::${file}::`))
        return mine.length > 0 && mine.every(([, st]) => st === 'pass' || st === 'skip')
      }
      const keep = files.filter((f) => !greenFile(f))
      verdict.reused += files.length - keep.length
      files = keep
    }
    verdict.selection[s.name] = { files: files === 'all' ? 'all' : files.length, why: typeof why === 'string' ? why : null }
    if (files !== 'all' && !files.length) continue
    let res = await runSuite(s, files)
    if (!res.results && !signal?.aborted) res = await runSuite(s, files)
    if (signal?.aborted) break
    if (!res.results) {
      verdict.broken.push({ suite: s.name, reason: res.reason })
      continue
    }
    for (const r of res.results) {
      const id = testId(s.name, r)
      rows.push({ id, status: r.status, ms: r.ms })
      if (r.status !== 'fail') continue
      const f = { id, file: r.file, name: r.name, msg: r.msg }
      record(
        f,
        await judge(
          f,
          (x) => rerun(s, x, checkout),
          async (x) => rerun(s, x, await ctx.targetCheckout()),
        ),
        s.name,
      )
    }
  }

  // 3. The ledger, then which commit broke what.
  ledger.appendResults(rows.map((r) => ({ run: req.id, sha: req.sha, tier: req.tier, ...r })))
  const passed = rows.filter((r) => r.status === 'pass').map((r) => r.id)
  ledger.recordClean(passed)
  if (req.tier === 'merge' && !signal?.aborted) ledger.removeKnown(req.target, passed)
  if (verdict.regressions.length && (req.commits?.length ?? 0) > 1 && !signal?.aborted) {
    await bisect(verdict.regressions, req.commits, {
      atCommit: ctx.atCommit,
      statusAt: async (g) => (g.suite === 'check' ? ((await checkFails(checksRun.get(g.id), checkout)).fail ? 'fail' : 'pass') : rerun(suiteOf.get(g.suite), g, checkout)),
    })
  } else for (const g of verdict.regressions) g.introducedBy = req.commits?.at(-1) ?? req.sha
  rmSync(tmp, { recursive: true, force: true })

  verdict.status = signal?.aborted ? 'cancelled' : verdict.regressions.length ? 'red' : verdict.broken.length ? 'env-broken' : 'green'
  verdict.ms = Date.now() - t0
  return verdict
}
```

```js
// scripts/verify/schedule.mjs
/**
 * What runs next (spec §The units — scheduler): merge before phase before commit, oldest first,
 * one merge per target at a time; queued commit requests on one branch fold into one run over
 * every commit they name, so a busy branch costs one run, not one per commit.
 */
export const PRIORITY = { merge: 0, phase: 1, commit: 2 }

/** `queued` oldest first → the requests to keep (survivors carry `commits` and `foldedFrom`) and the folded ids. */
export function fold(queued) {
  const keep = []
  const folded = []
  const byBranch = new Map()
  for (const r of queued) {
    if (r.tier !== 'commit') {
      keep.push(r)
      continue
    }
    const into = byBranch.get(r.branch)
    if (!into) {
      byBranch.set(r.branch, r)
      keep.push(r)
      continue
    }
    const merged = { ...r, commits: [...(into.commits ?? [into.sha]), ...(r.commits ?? [r.sha])], foldedFrom: [...(into.foldedFrom ?? []), into.id] }
    keep[keep.indexOf(into)] = merged
    byBranch.set(r.branch, merged)
    folded.push({ id: into.id, into: r.id })
  }
  return { keep, folded }
}

export function pickNext(queue, { running }) {
  const busy = new Set(running.filter((r) => r.tier === 'merge').map((r) => r.target))
  const order = [...queue].sort((a, b) => PRIORITY[a.tier] - PRIORITY[b.tier] || a.createdAt.localeCompare(b.createdAt) || a.id.localeCompare(b.id))
  return order.find((r) => !(r.tier === 'merge' && busy.has(r.target))) ?? null
}
```

```js
#!/usr/bin/env node
// scripts/verify/serve.mjs
/**
 * The verifier service — one per repo (spec §The units — service). Requests are files; the
 * service folds, schedules and runs them on `verify.workers` checkouts, writes verdicts, lands
 * merge-tier greens, and exits after `idleMs` with nothing queued or running. All state is in
 * .builder/verify/, so a crash loses nothing: on start, `running` requests return to `queued` and
 * orphaned databases are dropped.
 *
 *   node scripts/verify/serve.mjs <main checkout>     (started by verify.mjs; never by hand)
 */
import { openSync, closeSync, readFileSync, writeFileSync, unlinkSync, rmSync } from 'node:fs'
import { join } from 'node:path'
import { fileURLToPath } from 'node:url'
import { git, tryGit, sh } from './git.mjs'
import { openLedger, verifyDir } from './ledger.mjs'
import { loadVerify } from './config.mjs'
import { createPool } from './envpool.mjs'
import { selectSuites } from './select.mjs'
import { runRequest } from './run.mjs'
import { fold, pickNext } from './schedule.mjs'
import { ensureCheckout, commitExists, checkoutAt, mergedCheckout, setupIfNeeded, changedFiles, land } from './checkouts.mjs'
import { loadConfig } from '../config.mjs'

const MAX_LAND_ATTEMPTS = 5
const sleep = (ms) => new Promise((r) => setTimeout(r, ms))
const alive = (pid) => {
  try {
    process.kill(pid, 0)
    return true
  } catch (e) {
    return e.code === 'EPERM'
  }
}

/** The pid lock: true when this process holds it (taken now, or already ours). */
export function takeLock(root) {
  const p = join(verifyDir(root), 'serve.pid')
  for (let i = 0; i < 2; i++) {
    try {
      const fd = openSync(p, 'wx')
      writeFileSync(fd, String(process.pid))
      closeSync(fd)
      return true
    } catch {
      const pid = Number(readFileSync(p, 'utf8'))
      if (pid === process.pid) return true
      if (pid && alive(pid)) return false
      try {
        unlinkSync(p)
      } catch {}
    }
  }
  return false
}
const dropLock = (root) => {
  try {
    if (Number(readFileSync(join(verifyDir(root), 'serve.pid'), 'utf8')) === process.pid) unlinkSync(join(verifyDir(root), 'serve.pid'))
  } catch {}
}

const shell = (cmd, o) => sh(cmd, o)
const empty = (req, status, extra = {}) => ({ request: req.id, branch: req.branch, sha: req.sha, tier: req.tier, status, regressions: [], flakes: [], known: [], debt: [], broken: [], selection: {}, reused: 0, ms: 0, ...extra })

export async function serve(root, { idleMs = 10 * 60000, tickMs = 500, run = runRequest, verify = null } = {}) {
  const ledger = openLedger(root)
  if (!takeLock(root)) return 'locked'
  let v = verify
  let untested = false
  if (!v) {
    const r = loadVerify(root)
    // No verify: block (or no config) → nothing is configured to test, as a config with no gate blocks was:
    // runs are green and say so (`untested`). A block that is there but wrong is env-broken.
    if (!r.ok && /no verify: block|no \.claude\/builder\.md/.test(r.reason)) {
      v = { workers: 1, timeoutMs: 15 * 60000, setup: null, setupInputs: [], db: null, simulator: null, env: null, suites: [], checks: [] }
      untested = true
    } else if (!r.ok) {
      for (const q of ledger.requests((x) => x.state === 'queued' || x.state === 'running')) ledger.saveRequest({ ...q, state: 'done', doneAt: new Date().toISOString(), verdict: empty(q, 'env-broken', { broken: [{ suite: '-', reason: r.reason }] }) })
      dropLock(root)
      return 'idle'
    } else v = r.verify
  }
  const cfg = loadConfig(root)
  const walkEnv = cfg.ok ? cfg.agentWalk?.env ?? {} : {}
  const pool = createPool(v)
  for (const r of ledger.requests((x) => x.state === 'running')) ledger.saveRequest({ ...r, state: 'queued', startedAt: undefined })
  try {
    pool.dropOrphans()
  } catch {}

  const running = new Map()
  const slots = [...Array(v.workers).keys()]
  let idleSince = Date.now()

  const finish = (req, verdict) => {
    const cur = ledger.getRequest(req.id) ?? req
    if (cur.state === 'cancelled') {
      ledger.saveRequest({ ...cur, doneAt: new Date().toISOString(), verdict: { ...verdict, status: 'cancelled' } })
      return
    }
    if (verdict.requeue) {
      const attempts = (cur.attempts ?? 0) + 1
      if (attempts < MAX_LAND_ATTEMPTS) return ledger.saveRequest({ ...cur, state: 'queued', attempts, startedAt: undefined })
      verdict = empty(req, 'env-broken', { broken: [{ suite: '-', reason: `could not land after ${attempts} tries: ${verdict.reason}` }] })
    }
    const done = { ...cur, state: 'done', doneAt: new Date().toISOString(), verdict: { ...verdict, request: req.id, branch: req.branch, sha: req.sha, tier: req.tier } }
    ledger.saveRequest(done)
    for (const id of req.foldedFrom ?? []) {
      const f = ledger.getRequest(id)
      if (f) ledger.saveRequest({ ...f, state: 'done', doneAt: done.doneAt, verdict: done.verdict })
    }
  }

  const execute = async (req, slot, signal) => {
    if (!commitExists(root, req.sha)) return empty(req, 'gone')
    const targetSha = git(root, 'rev-parse', `refs/heads/${req.target}`)
    const checkout = ensureCheckout(root, slot)
    let sha = req.sha
    if (req.tier === 'merge') {
      const m = mergedCheckout(checkout, targetSha, req.sha, req.message ?? `Merge ${req.branch} into ${req.target}`)
      if (m.conflict) return empty(req, 'conflict', { files: m.files })
      sha = m.sha
    } else checkoutAt(checkout, req.sha)
    setupIfNeeded(checkout, v, (cmd) => shell(cmd, { cwd: checkout }))
    const mergeBase = tryGit(root, 'merge-base', targetSha, req.sha) ?? targetSha
    // The commit tier starts after the branch's last green; the phase and merge tiers cover the branch.
    const green = req.since || req.tier !== 'commit' ? null : ledger.lastGreen(req.branch)
    const base = req.since ?? (green && green.sha !== req.sha && tryGit(root, 'merge-base', '--is-ancestor', green.sha, req.sha) !== null ? green.sha : mergeBase)
    let targetCo = null
    const ctx = {
      verify: v,
      pool,
      ledger,
      checkout,
      targetSha,
      signal,
      baseEnv: {},
      lease: async (needs, o) => {
        for (;;) {
          const l = await pool.lease(needs, o)
          if (l) return needs.some((n) => n.kind === 'walk-env') ? { ...l, env: { ...walkEnv, ...l.env } } : l
          if (signal.aborted) throw new Error('cancelled')
          await sleep(1000)
        }
      },
      select: selectSuites,
      targetCheckout: async () => {
        if (!targetCo) {
          targetCo = ensureCheckout(root, `t${slot}`)
          checkoutAt(targetCo, targetSha)
          setupIfNeeded(targetCo, v, (cmd) => shell(cmd, { cwd: targetCo }))
        }
        return targetCo
      },
      atCommit: async (s) => {
        checkoutAt(checkout, s)
      },
    }
    // Every commit in the range, oldest first — what bisect walks to name the one that broke a test.
    const commits = (tryGit(root, 'rev-list', '--reverse', '--first-parent', `${base}..${req.sha}`) ?? '').split('\n').filter(Boolean)
    const verdict = await run({ ...req, sha, base, commits: commits.length ? commits : [req.sha], changed: changedFiles(root, mergeBase, req.sha) }, ctx)
    verdict.sha = req.sha
    if (untested) verdict.untested = true
    if (req.tier === 'merge') {
      verdict.merged = sha
      if (verdict.status === 'green') {
        const l = land(root, req.target, sha, targetSha)
        if (!l.ok) return { requeue: true, reason: l.reason }
        verdict.landed = sha
      }
    }
    return verdict
  }

  const start = (req, slot) => {
    const r = { ...req, state: 'running', startedAt: new Date().toISOString(), pid: process.pid }
    ledger.saveRequest(r)
    const abort = new AbortController()
    running.set(r.id, { req: r, abort })
    execute(r, slot, abort.signal)
      .catch((e) => empty(r, 'env-broken', { broken: [{ suite: '-', reason: String(e.message ?? e).slice(0, 1000) }] }))
      .then((verdict) => finish(r, verdict))
      .finally(() => {
        running.delete(r.id)
        slots.push(slot)
      })
  }

  try {
    for (;;) {
      for (const [id, h] of running) if (ledger.getRequest(id)?.state === 'cancelled') h.abort.abort()
      const { keep, folded } = fold(ledger.requests((x) => x.state === 'queued'))
      for (const f of folded) {
        const r = ledger.getRequest(f.id)
        if (r) ledger.saveRequest({ ...r, state: 'folded', foldedInto: f.into })
      }
      for (const r of keep) if (r.foldedFrom) ledger.saveRequest(r)
      while (slots.length) {
        const next = pickNext(
          keep.filter((r) => !running.has(r.id)),
          { running: [...running.values()].map((h) => h.req) },
        )
        if (!next) break
        keep.splice(keep.indexOf(next), 1)
        start(next, slots.shift())
      }
      if (running.size || keep.length) idleSince = Date.now()
      else if (Date.now() - idleSince >= idleMs) return 'idle'
      await sleep(tickMs)
    }
  } finally {
    dropLock(root)
  }
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const root = process.argv[2]
  if (!root) {
    console.error('usage: serve.mjs <main checkout>')
    process.exit(2)
  }
  serve(root).then(() => process.exit(0))
}
```

```js
 * verify — the verifier's client (docs/specs/2026-10-27-verifier-design.md). Builds, skills and the

 *
 *   verify.mjs request <worktree> <sha|HEAD> --tier commit|phase|merge [--target <b>] [--since <sha>] [--message <m>] [--tree]
 *   verify.mjs verdict <branch> [<sha>] [--json]
 *   verify.mjs wait <request> [--max <seconds>] [--json]       (default 540 — under one 10-minute Bash call)
 *   verify.mjs cancel <request>
 *   verify.mjs status [--json]
 *   (each takes --in <worktree>, default the cwd; the ledger is the main checkout's)
 *
 * Exit: 0 green · 1 red · 2 usage · 3 env-broken · 4 conflict · 5 gone/none · 6 cancelled · 75 pending.

import { openSync, readFileSync } from 'node:fs'
import { join, resolve } from 'node:path'
import { fileURLToPath } from 'node:url'

const EXIT = { green: 0, red: 1, 'env-broken': 3, conflict: 4, gone: 5, cancelled: 6 }
export const exitFor = (status) => EXIT[status] ?? 75

const plural = (n, w) => `${n} ${w}${n === 1 ? '' : 's'}`
export function summarize(v) {
  const head = [
    `verify ${v.tier} ${String(v.sha).slice(0, 7)} ${v.branch}: ${String(v.status).toUpperCase()}`,
    v.regressions.length && plural(v.regressions.length, 'regression'),
    v.flakes.length && plural(v.flakes.length, 'flake'),
    v.known.length && `${v.known.length} known`,
    v.debt?.length && `${v.debt.length} newly found debt`,
    v.broken.length && `${v.broken.length} broken`,
    v.reused && `${v.reused} reused`,
    v.untested && 'untested — the config has no verify: block',
    `${Math.round((v.ms ?? 0) / 1000)}s`,
  ].filter(Boolean)
  const lines = [head.join(' · ')]
  for (const g of v.regressions) {
    lines.push(`  ✗ ${g.id} — introduced by ${String(g.introducedBy).slice(0, 7)}${g.note ? ` (${g.note})` : ''}`)
    for (const l of String(g.msg ?? '').split('\n').slice(0, 6)) lines.push(`      ${l}`)
  }
  for (const b of v.broken) lines.push(`  ⚠ ${b.suite}: ${b.reason}`)
  if (v.files?.length) lines.push(`  conflict in: ${v.files.join(', ')}`)
  if (v.landed) lines.push(`  landed: ${v.landed.slice(0, 7)}`)
  const sel = Object.entries(v.selection ?? {}).map(([s, x]) => `${s} ${x.files === 'all' ? 'all' : x.files === 0 ? 'none' : plural(x.files, 'file')}`)
  if (sel.length) lines.push(`  selection: ${sel.join(', ')}`)
  return lines.join('\n')
}

const flag = (f) => argv.includes(f)
const opt = (f) => {

}
const positional = argv.filter((a, i) => !a.startsWith('--') && !['--tier', '--target', '--since', '--message', '--max', '--in'].includes(argv[i - 1]))
const die = (m) => {
  console.error(m)
  process.exit(2)

function ensureService(root) {
  try {
    const pid = Number(readFileSync(join(verifyDir(root), 'serve.pid'), 'utf8'))
    process.kill(pid, 0)
    return
  } catch {}
  const log = openSync(join(verifyDir(root), 'serve.log'), 'a')
  const idle = process.env.BUILDER_VERIFY_IDLE_MS
  spawn(process.execPath, ['-e', `import(${JSON.stringify(SERVE)}).then((m) => m.serve(${JSON.stringify(root)}${idle ? `, { idleMs: ${Number(idle)} }` : ''})).then(() => process.exit(0))`], { detached: true, stdio: ['ignore', log, log] }).unref()
}

function show(req, json) {
  const v = req.verdict
  if (json) console.log(JSON.stringify(v, null, 2))
  else console.log(summarize(v))
  process.exit(exitFor(v.status))
}

async function main() {
  const [cmd] = positional
  if (!cmd || flag('--help')) die(USAGE)
  const here = resolve(opt('--in') ?? (cmd === 'request' ? positional[1] ?? '.' : '.'))
  const root = mainRoot(here)
  const ledger = openLedger(root)

  if (cmd === 'request') {
    const [, wtArg, shaArg] = positional
    const tier = opt('--tier')
    if (!wtArg || !shaArg || !['commit', 'phase', 'merge'].includes(tier)) die(USAGE)
    const wt = resolve(wtArg)
    const branch = git(wt, 'rev-parse', '--abbrev-ref', 'HEAD')
    const sha = flag('--tree') ? tryGit(wt, 'stash', 'create') || git(wt, 'rev-parse', 'HEAD') : git(wt, 'rev-parse', shaArg)
    const cfg = loadConfig(root)
    const target = opt('--target') ?? (cfg.ok ? cfg.mergeInto : 'main')
    const req = ledger.newRequest({ worktree: wt, branch, sha, tier, target, ...(opt('--since') && { since: git(wt, 'rev-parse', opt('--since')) }), ...(opt('--message') && { message: opt('--message') }) })
    ensureService(root)
    console.log(req.id)
    return
  }
  if (cmd === 'verdict') {
    const [, branch, sha] = positional
    if (!branch) die(USAGE)
    const full = sha ? tryGit(here, 'rev-parse', sha) ?? sha : null
    const done = ledger.requests((r) => r.branch === branch && r.state === 'done' && r.verdict && (!full || r.sha === full)).at(-1)
    if (done) show(done, flag('--json'))
    const pending = ledger.requests((r) => r.branch === branch && ['queued', 'running', 'folded'].includes(r.state))
    console.log(pending.length ? `verify ${branch}: pending (${pending.map((r) => `${r.tier} ${r.state}`).join(', ')})` : `verify ${branch}: no verdict`)
    process.exit(pending.length ? 75 : 5)
  }
  if (cmd === 'wait') {
    const [, id] = positional

      const r = ledger.getRequest(id)
      if (!r) die(`no request ${id}`)

    }

    return
  }

    const cfg = loadConfig(root)
    const target = cfg.ok ? cfg.mergeInto : 'main'
    const out = { open: open.map((r) => ({ id: r.id, tier: r.tier, state: r.state, branch: r.branch, sha: r.sha.slice(0, 7), startedAt: r.startedAt ?? null })), flakes, known: [...ledger.known(target).ids] }

    }
    return
  }
  die(USAGE)
}
```

```js
// scripts/verify/fleet-hooks.mjs
/**
 * The fleet's calls into the verifier (spec §Merge tier, §The walk beside the merge tier): a held
 * merge request when a feature reaches the walk, its verdict, and the release that lands it.
 * The fleet is a node process, so it waits here without spending a model turn.
 */
import { execFileSync } from 'node:child_process'
import { fileURLToPath } from 'node:url'
import { git } from './git.mjs'
import { openLedger } from './ledger.mjs'

const CLIENT = fileURLToPath(new URL('./verify.mjs', import.meta.url))
const client = (cwd, ...args) => {
  try {
    return { status: 0, out: execFileSync(process.execPath, [CLIENT, ...args], { cwd, encoding: 'utf8', stdio: ['ignore', 'pipe', 'pipe'], env: process.env }).trim() }
  } catch (e) {
    return { status: e.status ?? 1, out: String(e.stdout ?? '').trim() }
  }
}

export function requestMerge(root, wt, { target, message }) {
  const ledger = openLedger(root)
  const head = git(wt, 'rev-parse', 'HEAD')
  const branch = git(wt, 'rev-parse', '--abbrev-ref', 'HEAD')
  const live = ledger.requests((r) => r.tier === 'merge' && r.branch === branch && r.sha === head && (['queued', 'running'].includes(r.state) || (r.state === 'done' && r.verdict?.status === 'green' && r.verdict.held))).at(-1)
  if (live) return live.id
  for (const r of ledger.requests((x) => x.tier === 'merge' && x.branch === branch && ['queued', 'running'].includes(x.state))) client(root, 'cancel', r.id, '--in', root)
  return client(wt, 'request', wt, 'HEAD', '--tier', 'merge', '--hold', '--target', target, '--message', message).out
}

export function mergeVerdict(root, branch, sha) {
  return openLedger(root).requests((r) => r.tier === 'merge' && r.branch === branch && r.sha === sha && r.state === 'done').at(-1)?.verdict ?? null
}

export async function awaitVerdict(root, id, { pollMs = 2000, signal = null } = {}) {
  const ledger = openLedger(root)
  for (;;) {
    const r = ledger.getRequest(id)
    if (r?.state === 'done' || (r?.state === 'cancelled' && r.verdict)) return r.verdict
    if (signal?.aborted) return null
    client(root, 'status', '--in', root) // keeps the service alive if it idled out
    await new Promise((res) => setTimeout(res, pollMs))
  }
}

export function release(root, id) {
  const r = client(root, 'release', id, '--in', root)
  if (r.status === 0) return { ok: true, sha: openLedger(root).getRequest(id).verdict.landed }
  return { ok: false, moved: r.status === 7, reason: r.out }
}
```

#!/usr/bin/env node
// scripts/verify/migrate.mjs
/**
 * A 5.x config's `## Quality gates` blocks → a 6.0 `verify:` block (spec §Config), for
 * /builder:init --update to show the human. It infers each line's runner from its command; what it
 * can't infer it says in `notes`. It prints; it never writes the config.
 *
 *   node scripts/verify/migrate.mjs [<repo root>]
 */
import { readFileSync } from 'node:fs'
import { join } from 'node:path'
import { fileURLToPath } from 'node:url'

const COMMENT = /\s{2,}#(.*)$|\s+#\s(.*)$/
const yq = (s) => (/^[\w./*{}@-]+$/.test(s) && !/[{},]/.test(s) ? s : JSON.stringify(s))

function blocks(body) {
  const out = []
  let app = null
  let inFence = false
  for (const line of body.split('\n')) {
    const h = /^###\s+(.+?)\s+—\s+fast\s*$/.exec(line)
    if (h) app = h[1]
    else if (/^###\s+Deep set/.test(line)) app = 'deep'
    else if (/^##\s/.test(line) && !/^##\s+Quality gates/.test(line)) app = null
    if (/^```/.test(line)) {
      inFence = !inFence
      continue
    }
    if (inFence && app && line.trim() && !/^\s*#/.test(line)) {
      const m = COMMENT.exec(line)
      out.push({ app, cmd: (m ? line.slice(0, m.index) : line).trim(), note: (m ? m[1] ?? m[2] ?? '' : '').trim() })
    }
  }
  return out
}

export function migrateGates(body, apps = []) {
  const suites = []
  const checks = []
  const notes = []
  const used = new Set()
  const name = (base) => {
    let n = base
    for (let i = 2; used.has(n); i++) n = `${base}-${i}`
    used.add(n)
    return n
  }
  for (const { app, cmd: raw, note } of blocks(body)) {
    const deep = app === 'deep'
    const cd = /^cd\s+(\S+)\s*&&\s*(.*)$/.exec(raw)
    const cwd = cd ? cd[1] : '.'
    const cmd = cd ? cd[2] : raw
    const scope = /@scoped\s+(\S+)/.exec(note)?.[1] ?? null
    const tiers = deep ? '[merge]' : /@typecheck/.test(note) ? '[commit, phase, merge]' : null
    const extra = [cwd !== '.' && `cwd: ${yq(cwd)}`, !deep && app && apps.includes(app) && `app: ${app}`, tiers && `tiers: ${tiers}`].filter(Boolean)
    if (/@known-red/.test(note)) notes.push(`${app}: "${cmd}" was @known-red — known failures are learned now (the target's failing test IDs), not declared; it is migrated as an ordinary line`)
    if (/@walk/.test(note)) notes.push(`${app}: "${cmd}" was @walk — if it needs the running dev env, add needs: [walk-env] to it`)
    let m
    if ((m = /^node\s+--test\s+(.*?)\s*(["']?[^\s"']*\.(?:test|spec)[^\s"']*["']?|["'][^"']+["'])\s*$/.exec(cmd))) {
      const files = m[2].replace(/^["']|["']$/g, '')
      suites.push(`    ${name(`${app}-test`)}: { runner: node-test, files: ${yq(files)}${m[1] ? `, args: ${yq(m[1])}` : ''}${extra.length ? `, ${extra.join(', ')}` : ''} }`)
    } else if (/\bvitest\b/.test(cmd)) suites.push(`    ${name(`${app}-vitest`)}: { runner: vitest${scope ? `, files: ${yq(scope)}` : ''}${extra.length ? `, ${extra.join(', ')}` : ''} }`)
    else if (/\bjest\b/.test(cmd)) suites.push(`    ${name(`${app}-jest`)}: { runner: jest${scope ? `, files: ${yq(scope)}` : ''}${extra.length ? `, ${extra.join(', ')}` : ''} }`)
    else if (/\bphpunit\b/.test(cmd)) suites.push(`    ${name(`${app}-phpunit`)}: { runner: phpunit${extra.length ? `, ${extra.join(', ')}` : ''} }`)
    else if (/\bplaywright\s+test\b/.test(cmd)) suites.push(`    ${name(`${app}-playwright`)}: { runner: playwright${scope ? `, files: ${yq(scope)}` : ''}${extra.length ? `, ${extra.join(', ')}` : ''} }`)
    else if (/\bxcodebuild\b.*\btest\b|--\s*--test\b/.test(cmd)) {
      const n = name(`${app}-xctest`)
      suites.push(`    ${n}: { runner: junit, command: ${yq(cmd)}, report: "FILL-ME.xml"${extra.length ? `, ${extra.join(', ')}` : ''} }`)
      notes.push(`${n}: an iOS suite — change it to { runner: xcodebuild, scheme: <scheme>, target: <test target> } (and needs: [simulator] with verify.simulator) so tests are tracked one by one`)
    } else {
      const n = name(`${app}-${(/(?:npm run|npx|node)\s+([\w:.-]+)/.exec(cmd)?.[1] ?? cmd.split(/\s+/)[0]).replace(/[^\w-]/g, '-')}`)
      const counted = /@delta/.test(note)
      const run = counted ? cmd.replace(/\s*\|\s*(grep -c|awk|wc -l).*$/, '') : cmd
      checks.push(`    ${n}: { run: ${JSON.stringify(run)}${counted ? ', compare: lines' : ''}${extra.length ? `, ${extra.join(', ')}` : ''} }`)
      if (counted) notes.push(`${n}: was a @delta count — compare: lines now fails only on a finding the target doesn't print; make the command print one finding per line (add match: "<regex>" to ignore timing lines)`)
    }
  }
  const yaml = ['verify:', '  workers: 2', ...(suites.length ? ['  suites:', ...suites] : []), ...(checks.length ? ['  checks:', ...checks] : [])].join('\n')
  return { yaml, notes }
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const root = process.argv[2] ?? process.cwd()

}

```js
// scripts/bench-replay-core.mjs
/**
 * The gate replay's decisions, free of the CLI (docs/specs/2026-10-27-verifier-design.md §Benchmark 1):
 * which commits an archived feature made, where its phases closed, and where the old gates ran.
 */
import { git } from './verify/git.mjs'

export function featureRange(repo, merged) {
  const [, base, tip] = git(repo, 'rev-list', '--parents', '-n1', merged).split(' ')
  if (!tip) throw new Error(`${merged} is not a merge commit`)
  const commits = git(repo, 'rev-list', '--reverse', '--first-parent', `${base}..${tip}`).split('\n').filter(Boolean)
  return { base, tip, commits }
}

const appOf = (file, apps) => apps.filter((a) => a.path && a.path !== '.' && (file === a.path || file.startsWith(`${a.path}/`))).sort((x, y) => y.path.length - x.path.length)[0]?.name ?? apps.find((a) => a.path === '.')?.name ?? null

export function phaseBoundaries(commits, apps, registry) {
  const out = []
  let cur = null
  let last = -1
  commits.forEach((c, i) => {
    const code = c.files.filter((f) => !f.startsWith(`${registry}/`))
    const owners = [...new Set(code.map((f) => appOf(f, apps)).filter(Boolean))]
    if (!owners.length) {
      if (cur) last = i
      return
    }
    const app = owners[0]
    if (cur && app !== cur) out.push({ index: last, app: cur })
    cur = app
    last = i
  })
  if (cur) out.push({ index: last, app: cur })
  return out
}

export function controlPoints(boundaries, shas, apps) {
  const pts = boundaries.map((b) => ({ sha: shas[b.index], args: [b.app], label: `phase ${b.app}` }))
  const touched = [...new Set(boundaries.map((b) => b.app))].sort((a, b) => apps.findIndex((x) => x.name === a) - apps.findIndex((x) => x.name === b))
  const tip = shas.at(-1)
  pts.push({ sha: tip, args: touched, label: 'end gates' }, { sha: tip, args: ['--deep', ...touched], label: 'verify deep' })
  return pts
}

const m = (ms) => `${Math.round(ms / 60000)}m`
export function summarize(rows) {
  const t = rows.reduce(
    (a, r) => ({
      cb: a.cb + r.control.blockingMs,
      cr: a.cr + r.control.reds,
      tb: a.tb + r.treatment.blockingMs,
      bg: a.bg + r.treatment.backgroundMs,
      ...Object.fromEntries(['regressions', 'flakes', 'known', 'debt', 'broken'].map((k) => [k, a[k] + r.treatment[k]])),
    }),
    { cb: 0, cr: 0, tb: 0, bg: 0, regressions: 0, flakes: 0, known: 0, debt: 0, broken: 0 },
  )
  const row = (name, cb, cr, tb, bg, x) => `| ${name} | ${m(cb)} | ${cr} | ${m(tb)} | ${m(bg)} | ${x.regressions} | ${x.flakes} | ${x.known} | ${x.debt} | ${x.broken} |`
  return [
    '| Feature | Old gates: blocking | Old gates: red runs | Verifier: blocking (phase + merge) | Verifier: background (commit) | Regressions | Flakes | Known | Newly found debt | Env-broken |',
    '|---|---|---|---|---|---|---|---|---|---|',
    ...rows.map((r) => row(r.feature, r.control.blockingMs, r.control.reds, r.treatment.blockingMs, r.treatment.backgroundMs, r.treatment)),
    row('**total**', t.cb, t.cr, t.tb, t.bg, t),
    '',
    `blocking time: ${t.cb ? Math.round((1 - t.tb / t.cb) * 100) : 0}% less · red results the verifier did not count against a feature: ${t.flakes + t.known + t.debt} · regressions it attributed to a commit: ${t.regressions}`,
  ].join('\n')
}
```

```js
#!/usr/bin/env node
// scripts/bench-replay.mjs
/**
 * The gate replay (spec §Benchmark 1): each archived feature's real commits, in a scratch clone,
 * through the old gates (control: gate.mjs from a checkout of builder's main) and through the
 * verifier (treatment: this checkout's scripts/verify), on the same machine. No models run.
 *
 *   node scripts/bench-replay.mjs <repo> --verify <verify block file> --control <builder main checkout>
 *        [--features a,b] [--setup "<cmd>"] [--env KEY=VAL]… [--out <dir>]
 *
 * <repo> is read, never written: everything happens in a clone under $TMPDIR. --verify holds the
 * repo's `verify:` block (from scripts/verify/migrate.mjs, reviewed); --env points both sides at a
 * scratch database, never a dev one.
 */
import { mkdtempSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs'
import { tmpdir } from 'node:os'
import { join, resolve } from 'node:path'
import { execFileSync, spawnSync } from 'node:child_process'
import { fileURLToPath } from 'node:url'
import { git } from './verify/git.mjs'
import { featureRange, phaseBoundaries, controlPoints, summarize } from './bench-replay-core.mjs'

const HERE = fileURLToPath(new URL('.', import.meta.url))
const argv = process.argv.slice(2)
const opt = (f) => (argv.includes(f) ? argv[argv.indexOf(f) + 1] : null)
const many = (f) => argv.flatMap((a, i) => (argv[i - 1] === f ? [a] : []))
const repo = resolve(argv[0] ?? '')
const verifyFile = opt('--verify')
const control = opt('--control')
if (!argv[0] || !verifyFile || !control) {
  console.error('usage: bench-replay.mjs <repo> --verify <file> --control <builder main checkout> [--features a,b] [--setup "<cmd>"] [--env KEY=VAL]… [--out <dir>]')
  process.exit(2)
}
const env = { ...process.env, ...Object.fromEntries(many('--env').map((p) => [p.slice(0, p.indexOf('=')), p.slice(p.indexOf('=') + 1)])), BUILDER_VERIFY_IDLE_MS: '5000' }
const out = resolve(opt('--out') ?? join(repo, '.builder', 'bench', `replay-${new Date().toISOString().slice(0, 16).replace(/[:T]/g, '')}`))
mkdirSync(out, { recursive: true })
const only = opt('--features')?.split(',') ?? null
const rows = readFileSync(join(repo, '.builder', 'fleet', 'archive.jsonl'), 'utf8').split('\n').filter(Boolean).map((l) => JSON.parse(l)).filter((r) => r.merged && (!only || only.includes(r.feature)))

const timed = (cmd, args, cwd) => {
  const t0 = Date.now()
  const r = spawnSync(cmd, args, { cwd, env, encoding: 'utf8', maxBuffer: 256 * 1024 * 1024 })
  return { ms: Date.now() - t0, status: r.status, out: `${r.stdout ?? ''}${r.stderr ?? ''}`.slice(-4000) }
}
const verify = (cwd, ...a) => timed(process.execPath, [join(HERE, 'verify', 'verify.mjs'), ...a], cwd)
const requestAndWait = (wt, tier, extra = []) => {
  const id = verify(wt, 'request', wt, 'HEAD', '--tier', tier, '--target', 'replay-target', ...extra).out.trim().split('\n').pop()
  const t0 = Date.now()
  let w
  do w = verify(wt, 'wait', id, '--max', '540', '--json')
  while (w.status === 75)
  return { ms: Date.now() - t0, verdict: JSON.parse(w.out.slice(w.out.indexOf('{'))) }
}

const results = []
for (const row of rows) {
  let range
  try {
    range = featureRange(repo, row.merged)
  } catch (e) {
    console.error(`${row.feature}: skipped — ${e.message}`)
    continue
  }
  const dir = mkdtempSync(join(tmpdir(), `replay-${row.feature}-`))
  const clone = join(dir, 'repo')
  execFileSync('git', ['clone', '-q', '--no-local', repo, clone])
  git(clone, 'checkout', '-q', '--detach', range.base)
  git(clone, 'branch', 'replay-target', range.base)
  const cfgText = git(clone, 'show', `${range.base}:.claude/builder.md`)
  const apps = [...cfgText.matchAll(/^\s*-\s*name:\s*(\S+)\s*\n\s*path:\s*(\S+)/gm)].map((m) => ({ name: m[1], path: m[2] }))
  const registry = /^registry:\s*(\S+)/m.exec(cfgText)?.[1] ?? 'docs/features'
  const commits = range.commits.map((sha) => ({ sha, files: git(clone, 'diff-tree', '--no-commit-id', '--name-only', '-r', sha).split('\n').filter(Boolean) }))
  const bounds = phaseBoundaries(commits, apps, registry)
  if (opt('--setup')) timed('/bin/bash', ['-c', opt('--setup')], clone)

  // Control: the old gates where 5.x ran them, foreground — all of it blocking.
  const control = { runs: [], blockingMs: 0, reds: 0 }
  for (const p of controlPoints(bounds, range.commits, apps)) {
    git(clone, 'checkout', '-q', '--detach', '--force', p.sha)
    const r = timed(process.execPath, [join(control, 'scripts', 'gate.mjs'), ...p.args, '--force'], clone)
    control.runs.push({ label: p.label, sha: p.sha.slice(0, 7), ms: r.ms, status: r.status })
    control.blockingMs += r.ms
    if (r.status === 1) control.reds++
  }
  const merged = (() => {
    git(clone, 'checkout', '-q', '--detach', '--force', range.base)
    git(clone, 'merge', '-q', '--no-ff', '-m', 'replay merge', range.tip)
    return git(clone, 'rev-parse', 'HEAD')
  })()
  const post = timed(process.execPath, [join(control, 'scripts', 'gate.mjs'), ...bounds.map((b) => b.app).filter((a, i, xs) => xs.indexOf(a) === i), '--force'], clone)
  control.runs.push({ label: 'post-merge', sha: merged.slice(0, 7), ms: post.ms, status: post.status })
  control.blockingMs += post.ms
  if (post.status === 1) control.reds++

  // Treatment: the verifier, fed the same commits.
  git(clone, 'checkout', '-q', '--detach', '--force', range.base)
  const block = readFileSync(verifyFile, 'utf8').trimEnd()
  writeFileSync(join(clone, '.claude', 'builder.md'), cfgText.replace(/\n---\n/, `\n${block}\n---\n`))
  const wt = join(dir, 'wt')
  git(clone, 'worktree', 'add', '-q', '-b', 'replay', wt, range.base)
  const treatment = { requests: [], blockingMs: 0, backgroundMs: 0, regressions: 0, flakes: 0, known: 0, debt: 0, broken: 0 }
  const note = (tier, r) => {
    const v = r.verdict
    treatment.requests.push({ tier, sha: String(v.sha).slice(0, 7), ms: r.ms, status: v.status, regressions: v.regressions.map((g) => g.id), flakes: v.flakes, known: v.known, debt: v.debt })
    if (tier === 'commit') treatment.backgroundMs += r.ms
    else treatment.blockingMs += r.ms
    treatment.regressions += v.regressions.length
    treatment.flakes += v.flakes.length
    treatment.known += v.known.length
    treatment.debt += v.debt.length
    treatment.broken += v.broken.length
  }
  const ends = new Set(bounds.map((b) => b.index))
  range.commits.forEach((sha, i) => {
    git(wt, 'reset', '-q', '--hard', sha)
    note('commit', requestAndWait(wt, 'commit'))
    if (ends.has(i)) note('phase', requestAndWait(wt, 'phase'))
  })
  note('merge', requestAndWait(wt, 'merge', ['--hold']))

  const result = { feature: row.feature, commits: range.commits.length, phases: bounds.length, control, treatment }
  writeFileSync(join(out, `${row.feature}.json`), JSON.stringify(result, null, 2) + '\n')
  results.push(result)
  console.log(`${row.feature}: old ${Math.round(control.blockingMs / 60000)}m blocking, ${control.reds} red · verifier ${Math.round(treatment.blockingMs / 60000)}m blocking + ${Math.round(treatment.backgroundMs / 60000)}m background`)
}
writeFileSync(join(out, 'REPORT.md'), `# Gate replay — ${new Date().toISOString().slice(0, 10)}\n\n${summarize(results)}\n`)
console.log(`report: ${join(out, 'REPORT.md')}`)
```
